# phase3a-retrieval-baseline / arm: 3a-dense-only-naive-chunks

Phase 3a control condition: fixed 512-token chunks (FixedSizeChunker, not the production ParagraphChunker), dense-only, k=5, no literal leg, no rerank, no query rewriting. Scored on dev. This is the baseline everything in Phase 4's ablations is measured against.
